# /build — проверка сборки и качества

Запусти ворота **Quality** из `.claude/rules/workflow.md`: подтверди, что проект собирается,
проходит линтер/форматтер и тесты.

## Что сделать
1. Вызови субагента **`build-validator`** (роль: `.claude/agents/build-validator.md`).
2. Передай ему команды проверки из раздела **Commands Reference** файла `CLAUDE.md`
   (сборка, линтер/форматтер, тесты). Если аргумент `$ARGUMENTS` задан — ограничь проверку
   указанной областью; иначе проверяй весь проект.
3. Если в `CLAUDE.md` команды не заданы — НЕ угадывай их: сообщи это как блокер и попроси
   дополнить `CLAUDE.md`.

## Что вернуть
Структурированный отчёт от `build-validator` (формат — в его файле):
`СТАТУС: GREEN|RED`, числа по сборке/линту/тестам, топ-проблемы с адресами и рекомендация,
кому передать (`server-developer` / `ui-developer` / `tester` / `architect`).

> Дисциплина билдов (`rules/index.md`): коммит допустим только при зелёном билде (0 ошибок),
> предупреждения просмотрены. Запускай `/build` после каждого нетривиального изменения.
