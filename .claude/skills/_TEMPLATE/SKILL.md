# Название скилла

> Канонический шаблон скилла. Копируй папку при создании нового скилла: имя папки = `name:`,
> внутри — `SKILL.md` (+ опционально вспомогательные файлы/скрипты рядом).
> Скилл — это **переиспользуемая инструкция/плейбук** для повторяющейся работы, в отличие от
> агента (роль/исполнитель) и правила (дисциплина). Держи скилл нейтральным; команды,
> зависящие от стека, бери из `CLAUDE.md`.

## Когда применять
Конкретные ситуации/триггеры, при которых этот скилл уместен.

## Когда НЕ применять
Границы, чтобы не подключать скилл зря (экономия).

## Шаги / процедура
Пошаговая инструкция. Ссылайся на роли (`.claude/agents/*`) и правила (`.claude/rules/*`),
а не дублируй их.

## Связанные роли и правила
Кого из агентов привлечь и какие правила соблюсти.

## Definition of Done
Чек-лист завершённости результата скилла.
