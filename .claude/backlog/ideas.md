# Ideas — технологический радар

Кандидаты на замену/апгрейд существующих решений, найденные во время `/maintain` (пункт 4) или
обычной работы. **Не список задач** — это предложения на согласование с пользователем, не
auto-adopt. Продуктовый бэклог фич — в GitHub Issues (`lopatnov/pressmark/issues`), не здесь.

Формат записи:

```
## <Что> — предложено <дата>
- **Заменяет:** <текущее решение/зависимость>
- **Зачем:** <какую боль решает, что даёт>
- **Цена перехода:** <объём работ, риски, breaking changes>
- **Статус:** предложено | согласовано | отклонено
```

Пока пусто — записи появятся по мере прохода `/maintain` или находок в обычной работе.
