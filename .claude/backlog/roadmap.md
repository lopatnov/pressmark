# Roadmap

Фазы в порядке **текущего приоритета**. Активный чек-лист — в `tasks.md`.
Когда фаза становится активной, детальный чек-лист переносится туда. Выполненные фазы — в `completed/`.

> **Это нейтральный скелет шаблона `.claude`.** Замени плейсхолдеры `<...>` на реальные фазы и
> задачи своего проекта. Управляет этим файлом роль `scrum-master` (см. `../rules/workflow.md`).

---

## Фаза 0 — Адаптация шаблона под Pressmark

- [x] `CLAUDE.md` заполнен: продукт, стек (.NET 10 + gRPC + EF Core + MSSQL, React 19 + TS + Vite,
      18 локалей), конвенции (backend partial-классы по под-доменам + мапперы/guards; frontend
      page + `useXxx` hook), команды сборки/линта/тестов.
- [x] Добавлен скилл `dependency-freshness` — обновление зависимостей до реально последних версий
      (включая мажоры, .NET SDK, React), не только Dependabot-патчи.
- [x] Добавлен `docs/extending-the-app.md` — как заводить новый gRPC-эндпоинт и новую страницу
      по образцу существующего кода.
- [x] `.gitignore` больше не блокирует `CLAUDE.md`/`.claude`/`Claude.log.md`/`docs/claude`.
- [ ] Ростер агентов не сокращён (лин-ядро из шаблона оставлено как есть) — при необходимости
      сузить/расширить роли под реальную нагрузку сессий, см. `rules/team.md`.

> **Фичи-бэклог продукта живёт в GitHub Issues** (`lopatnov/pressmark/issues`) и в корневом
> `CHANGELOG.md`, а не здесь — `.claude/backlog/` предназначен для сессионных задач Claude
> (см. `tasks.md` и `completed/`), не для продуктового roadmap.
