# Roadmap

Фазы верхнего уровня поддержки проекта, в порядке приоритета. **Продуктовый бэклог фич живёт в
GitHub Issues** (`lopatnov/pressmark/issues`) и в корневом `CHANGELOG.md`, не здесь —
`.claude/backlog/` предназначен для технологических заметок сессий Claude (`ideas.md`) и вот этих
фаз поддержки, не для продуктового roadmap.

---

## Фаза 0 — Адаптация под Pressmark (выполнено)

- [x] `CLAUDE.md` заполнен: продукт, стек (.NET 10 + gRPC + EF Core + MSSQL, React 19 + TS + Vite,
      18 локалей), конвенции (backend partial-классы по под-доменам + мапперы/guards; frontend
      page + `useXxx` hook), команды сборки/линта/тестов.
- [x] Скилл `dependency-freshness` — обновление зависимостей до реально последних версий (включая
      мажоры, .NET SDK, React), не только Dependabot-патчи.
- [x] `docs/extending-the-app.md` — как заводить новый gRPC-эндпоинт и новую страницу по образцу
      существующего кода.
- [x] Ростер агентов сокращён с 18 шаблонных ролей до 8, реально соответствующих объёму работы над
      этим проектом (см. `rules/team.md`); процесс упрощён с 9-ворот RACI до одного решающего
      правила «дирижёр делает сам, кроме перечисленных случаев» (см. `rules/workflow.md`).
- [x] Команда [`/maintain`](../commands/maintain.md) — плановый проход поддержки (зависимости,
      security-алерты, рефакторинг, технологический радар, PR с независимой ревизией).
